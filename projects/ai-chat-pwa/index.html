KONEKSI PRIBADI

Pengaturan API

Client ini mengirim permintaan langsung ke satu endpoint provider/router yang mendukung alias model otomatis. Tidak ada VPS atau backend aplikasi.

Gunakan ID yang tampil pada daftar model provider. Gunakan alias auto hanya jika memang disediakan provider/router; alias itu tidak memilih model dari API provider lain.

Key disimpan lokal di browser ini tanpa enkripsi. Jangan gunakan perangkat bersama atau situs yang tidak dipercaya. Key hanya dikirim ke Base URL yang kamu atur.

Endpoint harus kompatibel dengan OpenAI Chat Completions dan mengizinkan request browser (CORS). Provider tetap menentukan model tujuan, biaya, ketersediaan, dan batasan konten.
