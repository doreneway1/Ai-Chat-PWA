KONEKSI PRIBADI

Pengaturan API

Hubungkan client ke relay Cloudflare Worker milikmu, lalu uji koneksi provider sebelum menyimpan pengaturan.

Worker meneruskan request ke provider dan menangani CORS. Jangan gunakan URL Worker milik orang lain.

Gunakan ID yang tampil pada daftar model provider atau alias auto yang memang didukung endpoint tersebut.

Key disimpan lokal tanpa enkripsi. Key dan prompt diteruskan melalui Cloudflare Worker milikmu ke provider; Worker tidak menyimpannya.

Tes koneksi sebelum menyimpan.

Tes mengirim satu request chat pendek dan dapat memakai sedikit token. Endpoint harus kompatibel dengan OpenAI Chat Completions. Provider tetap menentukan model tujuan, biaya, ketersediaan, dan batasan konten.
