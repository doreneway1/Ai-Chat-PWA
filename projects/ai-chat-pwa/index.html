KONEKSI PRIBADI

Pengaturan API

Tambahkan koneksi provider dan model. Worker milikmu meneruskan request; uji setiap koneksi sebelum menyimpan.

Jangan gunakan URL Worker milik orang lain. Base URL provider harus HTTPS dan host-nya harus masuk allowlist Worker.

Daftar gratis di Brave Search API, lalu tempel key-nya di sini. Key diteruskan melalui Worker milikmu ke Brave hanya saat pencarian web aktif.

Mode gambar memakai provider yang sedang dipilih (atau provider teruji pertama) dan endpoint gambar OpenAI-compatible provider tersebut.

Brankas PIN. API key saat ini belum dienkripsi aplikasi.

Model per baris: ID model | fast,balanced,deep,default. Level Auto memilih level lokal tanpa panggilan router tambahan.

API key ada di localStorage; riwayat dan foto lampiran ada di IndexedDB browser—keduanya memakai penyimpanan perangkat dan tidak dienkripsi aplikasi. Hapus chat untuk menghapus lampirannya, atau hapus data situs di pengaturan browser untuk menghapus semua data lokal. Key, prompt, dan gambar yang dikirim melewati Worker milikmu lalu ke provider.
